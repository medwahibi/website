# Med Wahibi - Portfolio Website

A professional portfolio website showcasing graphic design, AI linguistics research, and branding projects.

## 🌟 Features

- **Responsive Design** - Fully optimized for mobile, tablet, and desktop
- **Modern UI/UX** - Clean, professional interface with smooth animations
- **Project Showcase** - Portfolio sections for branding, graphic design, and web projects
- **Interactive Navigation** - Multi-page navigation with smooth transitions
- **Contact Form** - Multi-step questionnaire for project inquiries

## 🚀 Quick Start

### Local Development

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd medwahibi-portfolio
   ```

2. **Open locally**
   - Simply open `index.html` in your browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # Visit http://localhost:8000
     ```

### Deployment

#### Option 1: GitHub Pages
1. Push to GitHub
2. Go to Settings → Pages
3. Select `main` branch → Save
4. Your site will be live at `https://username.github.io/repo-name/`

#### Option 2: Quick Deploy Script
```bash
./deploy.sh
# Follow the prompts to push to GitHub
```

#### Option 3: Netlify/Vercel
- Drag and drop the project folder to [Netlify](https://netlify.com) or [Vercel](https://vercel.com)
- Or connect your GitHub repository for automatic deployments
